# Задания к Модулю 3: Агрегация и Группировка

## Задание 3.1. Агрегаты
1.  Посчитайте общее количество пользователей в системе.
2.  Найдите суммарную длительность всех фильмов в минутах.
3.  Узнайте минимальный и максимальный год выпуска фильма в каталоге.
4.  Посчитайте средний баланс пользователей.

## Задание 3.2. Группировка (GROUP BY)
1.  **Популярность жанров:** Посчитайте количество фильмов в каждом жанре (`genre_id`, count).
2.  **Активность зрителей:** Посчитайте, сколько раз каждый пользователь смотрел фильмы (таблица `views`, группировка по `user_id`).
3.  **Финансы:** Посчитайте общую сумму платежей (`sum(amount)`) в разбивке по статусу платежа (`status`).

## Задание 3.3. HAVING
1.  Найдите жанры, в которых больше 2 фильмов.
2.  Найдите пользователей, которые суммарно потратили на просмотры более 300 минут (таблица `views`, сумма `watched_min`).
3.  Определите годы, в которые вышло более 1 фильма (группировка по `release_year`).

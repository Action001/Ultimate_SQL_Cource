# Теория к Модулю 6: Продвинутые запросы

## 6.1. Подзапросы (Subqueries)

Запрос внутри запроса. Бывают:
*   В блоке `WHERE`: `WHERE id IN (SELECT ...)`
*   В блоке `FROM`: `FROM (SELECT ...) AS alias`
*   В блоке `SELECT`: Вычисляемое поле.

## 6.2. Common Table Expressions (CTE)

Временные именованные наборы данных. Делают код чище.

**Синтаксис:**
```sql
WITH MyCTE AS (
    SELECT ...
)
SELECT * FROM MyCTE WHERE ...;
```

## 6.3. Оконные функции (Window Functions)

Позволяют считать агрегаты, не схлопывая строки, или нумеровать строки внутри групп.

**Ключевое слово:** `OVER`.

*   `ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...)` — нумерация строк внутри группы.
*   `RANK()` — рейтинг (с пропусками при равенстве).
*   `LAG` / `LEAD` — доступ к предыдущей/следующей строке.

## 6.4. Временные таблицы (Temporary Tables)

Используются для хранения промежуточных результатов, которые нужны в нескольких шагах сложного скрипта. Живут только в рамках сессии или транзакции.

**Создание:**
*   **MSSQL:** `CREATE TABLE #MyTemp (...)` или `SELECT * INTO #MyTemp FROM ...` (имя начинается с `#`).
*   **PostgreSQL:** `CREATE TEMPORARY TABLE MyTemp (...)`.

**Отличие от CTE:**
*   CTE — это "виртуальное" представление, существует только для одного запроса.
*   Temp Table — это физическая таблица (в tempdb), можно индексировать, обновлять и использовать в нескольких запросах подряд.

# Задания к Модулю 4: JOINs

## Задание 4.1. INNER JOIN
1.  **Каталог:** Выведите список фильмов с названиями их жанров (соедините `movies` и `genres`).
2.  **История:** Покажите, кто и что смотрел: Имя пользователя, Название фильма, Дата просмотра (таблицы `users`, `movies`, `views`).
3.  **Оценки:** Выведите Имя пользователя, Название фильма и Текст отзыва для всех оставленных отзывов.

## Задание 4.2. LEFT JOIN
1.  **Без подписки:** Найдите пользователей, у которых нет ни одной записи в таблице `subscriptions`. (Подсказка: `LEFT JOIN` + `WHERE subscription_id IS NULL`).
2.  **Непопулярные жанры:** Выведите все жанры и количество фильмов в них. Важно: жанры без фильмов тоже должны попасть в список с количеством 0.

## Задание 4.3. Сложные задачи
1.  **Полный профиль:** Выведите имя пользователя, название его текущего тарифного плана (если есть активная подписка) и количество денег на балансе.
2.  **Финансовый отчет:** Выведите список всех пользователей и сумму их успешных платежей. Если платежей не было, вывести 0 (или NULL).

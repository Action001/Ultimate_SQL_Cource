# Теория к Модулю 1: Основы выборки данных (DQL)

## 1.1. Простая выборка (SELECT)

Оператор `SELECT` используется для извлечения данных из таблиц.

**Синтаксис:**
```sql
SELECT column1, column2 FROM table_name;
```

*   `SELECT *` — выбрать все столбцы.
*   `DISTINCT` — убрать дубликаты строк.
*   `TOP N` (MSSQL) / `LIMIT N` (PostgreSQL) — ограничить количество возвращаемых строк.
*   `ORDER BY column [ASC|DESC]` — сортировка (по возрастанию | по убыванию).

## 1.2. Фильтрация (WHERE)

Оператор `WHERE` позволяет выбирать только те строки, которые удовлетворяют условию.

**Логические операторы:**
*   `AND` — И (оба условия верны)
*   `OR` — ИЛИ (хотя бы одно условие верно)
*   `NOT` — НЕ (инверсия)

**Операторы сравнения:**
*   `=`, `!=` (или `<>`), `>`, `<`, `>=`, `<=`
*   `BETWEEN a AND b` — диапазон (включительно).
*   `IN (1, 2, 3)` — совпадение с одним из списка.
*   `LIKE 'pattern'` — поиск по маске (`%` - любая строка, `_` - любой символ).

## 1.3. Работа с NULL

`NULL` — это отсутствие значения. Это не 0 и не пустая строка.

*   `IS NULL` — проверка на пустоту.
*   `IS NOT NULL` — проверка на заполненность.

**Важно:** Любое сравнение с NULL (`= NULL`, `> NULL`) возвращает `UNKNOWN` (ложь). Используйте только `IS NULL`.

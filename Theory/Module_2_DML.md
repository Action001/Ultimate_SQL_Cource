# Теория к Модулю 2: Модификация данных (DML)

Data Manipulation Language (DML) — это команды для изменения содержимого таблиц.

## 2.1. Вставка данных (INSERT)

Добавление новых строк в таблицу.

**Синтаксис:**
```sql
INSERT INTO table_name (col1, col2)
VALUES (val1, val2);
```

*   Порядок значений в `VALUES` должен строго соответствовать порядку столбцов в `INSERT INTO (...)`.
*   Столбцы с `IDENTITY`/`SERIAL` (автоинкремент) обычно пропускают.
*   Можно вставлять несколько строк сразу через запятую.

## 2.2. Обновление данных (UPDATE)

Изменение существующих записей.

**Синтаксис:**
```sql
UPDATE table_name
SET col1 = new_val1, col2 = new_val2
WHERE condition;
```

**Опасно:** Если забыть `WHERE`, обновятся **ВСЕ** строки в таблице! Всегда проверяйте условие `SELECT`-ом перед `UPDATE`.

## 2.3. Удаление данных (DELETE)

Удаление строк.

**Синтаксис:**
```sql
DELETE FROM table_name
WHERE condition;
```

*   `DELETE` удаляет строки, но сохраняет структуру таблицы.
*   `TRUNCATE TABLE` — очищает таблицу полностью (быстрее, сбрасывает счетчики ID), но не работает, если есть внешние ключи (Foreign Keys).
*   **Foreign Key Constraints:** Нельзя удалить запись, на которую ссылаются другие таблицы (например, жанр, если есть фильмы этого жанра). Сначала нужно удалить или обновить зависимые записи.

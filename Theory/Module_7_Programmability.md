# Теория к Модулю 7: Программируемые объекты

Это уже "Backend на стороне БД". Синтаксис сильно зависит от СУБД (T-SQL vs PL/pgSQL).

## 7.1. Stored Procedures (Хранимые процедуры)
Набор команд, сохраненный под именем. Могут менять данные, использовать транзакции, циклы, переменные.

*   `CREATE PROCEDURE`
*   `EXEC` / `CALL`

**Транзакции:**
Гарантируют атомарность (все или ничего).
`BEGIN TRANSACTION` -> `COMMIT` (успех) / `ROLLBACK` (откат при ошибке).

## 7.2. User Defined Functions (Функции)
Возвращают значение (скалярное или таблицу). Обычно используются в `SELECT` или `WHERE`. В отличие от процедур, обычно не могут менять данные в таблицах.

## 7.3. Triggers (Триггеры)
Скрипты, срабатывающие автоматически при событиях (`INSERT`, `UPDATE`, `DELETE`).

*   **AFTER**: Срабатывает после изменения.
*   **INSTEAD OF** / **BEFORE**: Срабатывает до изменения (можно отменить или подменить данные).
*   **Магические таблицы:**
    *   MSSQL: `inserted`, `deleted`.
    *   Postgres: `NEW`, `OLD`.

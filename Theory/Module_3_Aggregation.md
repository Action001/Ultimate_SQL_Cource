# Теория к Модулю 3: Агрегация и Группировка

Используется для построения отчетов и аналитики.

## 3.1. Агрегатные функции

Функции, которые принимают набор значений (столбец) и возвращают одно число.

*   `COUNT(*)` — количество строк.
*   `COUNT(column)` — количество не-NULL значений в столбце.
*   `SUM(column)` — сумма.
*   `AVG(column)` — среднее арифметическое.
*   `MIN(column)` / `MAX(column)` — минимум и максимум.

## 3.2. Группировка (GROUP BY)

Позволяет применять агрегатные функции не ко всей таблице, а к группам строк.

**Пример:** Посчитать средний рейтинг *для каждого жанра*.
```sql
SELECT genre_id, AVG(rating)
FROM movies
GROUP BY genre_id;
```

## 3.3. Фильтрация групп (HAVING)

`WHERE` фильтрует строки **ДО** группировки.
`HAVING` фильтрует результаты **ПОСЛЕ** группировки (фильтр по агрегатным функциям).

**Пример:** Показать жанры, где средний рейтинг > 8.
```sql
SELECT genre_id
FROM movies
GROUP BY genre_id
HAVING AVG(rating) > 8;
```

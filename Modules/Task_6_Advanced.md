# Задания к Модулю 6: Advanced SQL

## Задание 6.1. Подзапросы
1.  **Выше среднего:** Найдите фильмы, рейтинг которых выше среднего рейтинга всех фильмов в базе.
2.  **Активные:** Найдите пользователей, которые смотрели хотя бы один фильм за последние 30 дней (используйте `IN` или `EXISTS` с подзапросом к таблице `views`).

## Задание 6.2. CTE
1.  **Топ зрителей:** С помощью CTE сформируйте список пользователей с количеством их просмотров, а затем в основном запросе выберите только тех, у кого больше 3 просмотров.
2.  **Богатые клиенты:** Используя CTE, найдите средний чек платежа, а потом выведите платежи, которые больше этого среднего.

## Задание 6.3. Оконные функции
1.  **История подписок:** Для каждого пользователя пронумеруйте его подписки от самой новой к самой старой (`ROW_NUMBER`).
2.  **Топ в жанре:** Для каждого жанра выведите самый рейтинговый фильм (или топ-3), используя `RANK` или `ROW_NUMBER` с `PARTITION BY genre_id`.
3.  **Предыдущий просмотр:** Выведите список просмотров пользователя с id=1, добавив колонку "Дата ПРЕДЫДУЩЕГО просмотра" (`LAG`).

## Задание 6.4. Временные таблицы
1.  **Сложный расчет:**
    *   Шаг 1: Создайте временную таблицу (или используйте `SELECT INTO`), куда сохраните список пользователей, которые потратили больше 1000 рублей (id и сумма).
    *   Шаг 2: Из этой временной таблицы удалите тех, кто не заходил в систему последние 3 месяца.
    *   Шаг 3: Выведите финальный список оставшихся "ценных и активных" клиентов.

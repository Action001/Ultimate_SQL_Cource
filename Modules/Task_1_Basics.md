# Задания к Модулю 1: Основы выборки

## Задание 1.1. Знакомство с данными
1.  Вывести список всех фильмов (название, год релиза).
2.  Получить список всех уникальных жанров, которые есть в базе.
3.  Вывести топ-3 самых длинных фильма, отсортированных по убыванию длительности.
4.  Вывести 5 самых свежих регистраций пользователей (по дате регистрации).

## Задание 1.2. Фильтрация
1.  Найти все фильмы, выпущенные после 2015 года.
2.  Найти фильмы с рейтингом от 8.0 до 9.0 (используя `BETWEEN`).
3.  Найти фильмы жанров с ID 1, 2 и 5 (используя `IN`).
4.  Найти фильмы, название которых начинается на букву "М" (используя `LIKE`).
5.  Найти пользователей с email в домене `@mail.com`.

## Задание 1.3. NULL и сложные условия
1.  Найти пользователей, у которых НЕ заполнено поле `last_activity` (ни разу не заходили).
2.  Найти фильмы, у которых есть возрастное ограничение (min_age > 0) И рейтинг выше 7.5.
3.  Найти фильмы жанра "Фантастика" (genre_id=1) ИЛИ фильмы, выпущенные до 2000 года.
